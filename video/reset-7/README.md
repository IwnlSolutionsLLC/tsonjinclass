## Шинжлэх ухааны үүднээс зассан хэсгүүд (voice/script.json)

- «200–300% ихээр» допамин — баталгаатай тоо биш тул хассан.
- 3 дахь өдөр: «Ганцхан удаа харчих» гэж шивнэдэг нь **шагналын төв**; урд духны гадаргуу (prefrontal cortex) бол түүнийг **эсэргүүцдэг** өөрийгөө хянах төв.
- Хүлээн авагчид «өөрийгөө цэвэрлэх» → «амарч, аажмаар дахин мэдрэмтгий болох замын эхлэл» (энэ нь 2 хоногт дуусдаггүй).
- Тестостерон: «нэгэн судалгаагаар … түр зуур оргилдоо» (жижиг судалгаа, үр дүн нь түр зуурынх).
- 7 дахь өдөр: «допамины систем хэвийн түвшиндээ буцлаа» → «сэргэх замдаа орлоо».
- «Допамин даавар» → «допамины түвшин» (тархинд допамин нь мэдрэлийн дамжуулагч).

## Дахин үүсгэх

```bash
ELEVENLABS_API_KEY=... python3 voiceover.py   # дуу хоолой (текст: voice/script.json)

```
API түлхүүрийг зөвхөн environment-ээр дамжуулна — репозиторт бүү хадгал.
