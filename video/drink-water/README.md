## Дахин үүсгэх / засах

Шаардлага: Node.js 18+, Playwright (Chromium), ffmpeg, Python 3 + numpy.

```bash
node render.mjs                       # бүтэн видео -> us-uugaarai.mp4 (~10 мин)
node render.mjs --stills 3,15,45.9    # тухайн секундын PNG зураг -> build/stills/
node render.mjs --from 20 --to 27     # хэсгийг хурдан урьдчилж үзэх -> build/preview-20-27.mp4
```

`index.html`-ийг хөтөчөөр нээвэл видеог шууд тоглуулж, гүйлгэж үзэж болно (`?t=12.5` — тухайн секундээс).

- `src/scenes.js` — цаг хугацааны хуваарь, кадр бүрийн найруулга, тоолуур, өнгө засвар
- `src/landscape.js` — тэнгэр, нар, хээр, гэр, зэрэглээ, шороо
- `src/figure.js` — хүн, уруул, гар
- `src/science.js` — судас ба цусны эс, бөөр, тархи, ЭКГ
- `src/pov.js`, `src/glass.js` — хагарах газар ба хий үзэгдлийн гол; устай аяга
- `audio.py` — бүх дууг `build/cues.json`-оос (хуудаснаас гаргасан цагийн хуваарь) үүсгэнэ
- `render.mjs` — кадр бүрийг Chromium-д зурж, ffmpeg-ээр MP4 болгоно
