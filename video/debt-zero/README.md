**Видео:** [`or-alga-bolvol.mp4`](or-alga-bolvol.mp4) — 1080×1920 (Reels / TikTok / Shorts), 30 fps, 2:57, монгол дуу хоолойтой (ElevenLabs `eleven_v4`, Sodtsetseg), H.264 + AAC.

## Дахин үүсгэх

```bash
ELEVENLABS_API_KEY=... python3 voiceover.py   # voice/01.mp3 … manifest.json, manifest.js (текст: voice/script.json)
node render.mjs                               # бүтэн видео (~20 мин)
node render.mjs --stills 10,60,120            # PNG зураг -> build/stills/
node render.mjs --audio                       # зөвхөн дууг дахин холих
```

API түлхүүрийг зөвхөн environment-ээр дамжуулна — репозиторт бүү хадгал. `src/city.js` — тэнгэр, Төрийн ордон, талбай, хүмүүс, гэр хороолол; `src/props.js` — утас, терминал, АТМ, дэлгүүр, диаграм; `src/scenes.js` — цагийн хуваарь ба кадрууд; `audio.py` — дуу.
