# 12-2 ангийн вэб сайт

Хичээлийн хуваарь, зургийн цомог (зураг + видео), сурагчдын хувийн хавтас, **Дугуйлангийн хуваарь**, **СУРАХ БИЧИГ** болон **DOODLE дурсамжийн самбар**. Төгсөх ангийн шинэ загвар, утас болон компьютерт тохирох дэлгэцтэй. Цэвэр PHP + HTML + JS; тусдаа SQL өгөгдлийн сан шаардлагагүй, хувийн ажил болон дурсамжийг сервер дээр хадгална.

## Суулгах

**Шууд камер, микрофон:** одоогийн `/admin.php#cctv` удирдлагын хэсэгт үзэж, сонсоно. Samsung дэлгэцийн нэг удаагийн тохиргоо `/admin.php#camera-setup` удирдлагын хэсэгт байна. Одоогийн удирдлагын нууц үгийг ашиглана. Chrome-ийн камер, микрофоны зөвшөөрлийг анх өгсний дараа холбосон дэлгэц сайт нээхэд автоматаар дамжуулна. Хуваарь болон бусад хэсэг солих, өөр Chrome таб харахад 12-2 таб нээлттэй байвал үргэлжилнэ; LIVE тэмдэг, зогсоох товч харагдана. Бичлэг хадгалахгүй. [Бүрэн тохиргоо](CCTV-SETUP.md), [өөр сүлжээний TURN сервер](deploy/cctv-turn/README.md).

1. Бүх файлыг вэб серверийн үндсэн хавтсанд (webroot) хуулна. Pterodactyl дээр File Manager эсвэл SFTP ашиглана.
2. `database/` хавтас болон доторх хавтсууд PHP-д **бичих эрхтэй** байх ёстой.
3. Сайтаа нээгээд `/admin.php` руу орно. Энэ үед `database/setup.php` файл үүснэ. Pterodactyl-ийн File Manager-ээс уг файлыг нээж, доторх `"code"`-ийн утгыг (жишээ нь `K7Q2MX9A`) хуулна. Түүнийг «Тохиргооны код» талбарт оруулаад **админ нууц үгээ** (8+ тэмдэгт) үүсгэнэ. Код зөвхөн сервер дээр харагддаг тул сайт руу орсон өөр хүн админ болж чадахгүй. Нууц үг үүссэний дараа `setup.php` автоматаар устна.
   - `ai-settings.php`, `12-2-ai-server-settings.php`, `spotify-settings.php` болон `database/` хавтас нь API түлхүүр, хувийн өгөгдөл агуулдаг тул git репозиторт ордоггүй (`.gitignore`). Эдгээрийг зөвхөн сервер дээр хадгална.
4. Нууц үгээ мартвал `database/admin.php` файлыг устгаад 3-р алхмыг давтана. Зураг, хуваарь хэвээр үлдэнэ.
5. Олон удаа буруу оролдсоны улмаас нэвтрэх түгжигдвэл 10 минут хүлээнэ, эсвэл `database/security.php` файлыг устгана.

## Шинэчлэх (сайт аль хэдийн ажиллаж байгаа бол)

Хуучин зураг, хуваарь, нууц үг бүгд хэвээр үлдэнэ.

1. **Нөөц:** Pterodactyl File Manager-ээс `database/` хавтсыг бүхэлд нь архивлаж татаж авна. Хувийн хавтас, сурах бичгийн ажил, DOODLE-ийн хуудсууд болон зураг/GIF-ийн хуулбарыг хамтад нь нөөцөлнө.
2. Шинэчлэлийн ZIP-г webroot руу хуулж, **application файлуудыг дарж бичнэ**. `inc/`, `assets/` доторх бүх шинэ файл, тухайлбал `assets/data/` болон `assets/img/doodle/`-ийг хамт шинэчилнэ.
3. Одоо байгаа **`database/` хавтсыг устгахгүй, багцын хоосон өгөгдлөөр солихгүй** — зураг, хуваарь, нууц үг, хувийн ажил болон дурсамж тэнд байна.
4. Сайтаа нээгээд «Цомог»-ийг нээнэ. Анх нээхэд хуучин зургууд таах боломжгүй шинэ нэр авч (нэр, огноо нь хадгалагдана) цомогт гарна.
5. **Удирдлага → Зургийн сан → «Бүгдийг үүсгэх»** дарж хуучин зураг, видеоны жижиг хувилбарыг (preview) үүсгэнэ. Ингэснээр цомог хурдан ачаална. Дуустал хуудсаа хаалгүй байлгана. Зогсоосон бол дахин дарахад үлдсэнээс нь үргэлжилнэ.
   - Зураг (JPG, PNG, WebP, GIF) — серверт үүснэ, утасны зургийн эргэлтийг засна.
   - Видео — таны хөтөч үүсгэнэ.
   - HEIC (iPhone) — серверт үүсгэх боломжгүй; Safari-аар Удирдлагад орж дарвал үүснэ.
   - Үүсээгүй хуучин зургийг ч цомог үзэхэд сервер автоматаар жижигрүүлж үзүүлнэ.

## Цомгийн код

- «Цомог» табыг нээхэд **4 оронтой код** асууна. Анхдагч код нь **4200**. Удирдлага → «Цомгийн код» хэсгээс сольж болно. Код солиход бүх хүн цомгоос гарна.
- Код мэдэх хүн бүр зураг, видео **нэмж** чадна, харин **устгаж чадахгүй**. Устгах эрх зөвхөн админд байна.
- Кодоо оруулсан хүний нэвтрэлт 12 цаг хүчинтэй, хөтчөө хаахад ч дуусна. «Түгжих» товчоор шууд гарч болно.
- 5 удаа буруу код оруулбал тухайн төхөөрөмж 10 минут түгжигдэнэ.

## AI CHAT — IwnlX Ai

- **AI CHAT** нь `egune-nano` API ашиглана. Сурагч нэрээ сонгож, хувийн хавтасны кодоор нэвтэрнэ; олон хувийн яриа серверт хадгалагдаж, өөр төхөөрөмжөөс үргэлжилнэ.
- Хэрэглэгчийн өгсөн system prompt-ыг ашиглаж, `USERNAME`-ийг тухайн сурагчийн нэрээр солино. Thinking горимыг унтрааж, `<think>...</think>` хэсгийг хадгалах болон харуулахаас өмнө арилгана. IwnlX Ai нь сайтын туслахын нэр; бодит API нь Egune.
- Хариулт нь Egune API-аас ирнэ; бэлэн мэндчилгээг AI хариу болгон орлуулахгүй. Загварын хариуны чанар, латин үсгээр бичсэн Монгол хэлний ойлголт болон баримтын зөв байдал баталгаатай биш. Үйлчилгээ хариу өгөхгүй үед алдааг ил тод харуулна.
- Ердийн хариулт **500 токен**, дэлгэрэнгүй сонголт **1200 токен** хүртэл. Сүүлийн **8000 тэмдэгт / 20 зурвас** контекстэд багтана; серверт бүтэн яриа хадгалагдана. Хуучин мэдээллийг дахин сануулах хэрэгтэй байж болно.
- Анхны хязгаар **20 хүсэлт / сурагч / өдөр**, **80 хүсэлт / сайт / өдөр**. Админд хязгаар, Egune түлхүүр, сонголтот төгрөгийн нийт хэрэглээний тооцоолсон хязгаарыг тохируулна. Төгрөгийн тооцоо нь өгсөн зааврын ₮900 оролт / ₮4900 гаралт / 1 сая токен дээр үндэслэнэ; бодит үлдэгдэл биш.
- Хүсэлт хэрэглэгч илгээхэд л гарна. Автомат AI хураангуй, арын дуудлага, автоматаар дахин төлбөртэй илгээлт байхгүй. Давхар хүсэлтийг idempotency дугаараар хамгаална.
- `C122_EGUNE_API_KEY` environment эсвэл PHP хамгаалалттай `ai-settings.php` файлын `eguneApiKey`-г ашиглана. **Админ → AI CHAT** хэсгээс түлхүүр хадгалж болно. Түлхүүр клиент JS/HTML-д буцахгүй.
- Өгсөн түлхүүртэй **ai-settings.php** нь application ZIP-ээс тусдаа хувийн файл. Үүнийг **`index.php`-тэй нэг үндсэн хавтаст** байршуулна. Админаас AI тохиргоо хадгалахад мөн энэ файлд бичнэ; PHP-д уг файл болон үндсэн хавтас бичих эрхтэй байх ёстой. Үндсэн файл хараахан байхгүй бол хуучин `database/ai-settings.php`-г уншина. Үндсэн файл байвал тэр тохиргоог ашиглана. Энэ файлыг нийтийн репозитор эсвэл бусдад тараах багцад оруулахгүй.
- Яриа болон хэрэглээ `database/ai-chat/` дотор хадгалагдана. Хогийн савнаас яриаг сэргээж болно. [AI CHAT-ийн мэдээлэл](ai-privacy.php)-д хадгалалт, Egune руу дамжуулдаг контекст болон зардлыг тайлбарласан.

## Music — нэг дэлгэцийн Spotify тоглуулагч

- **Music** дотор Spotify-оос шууд дуу хайж, тоглуулна. Smart Mix (автомат холих) болон аудио сан хасагдсан; өмнө нэмсэн аудио плейлистэд үлдсэн бол холилгүй дараалан тоглоно. Том дэлгэцийн хөтөч дээр **нэг Spotify Premium бүртгэлээр** холбогдоно; сурагч бүр тусдаа Spotify бүртгэлээр нэвтрэх шаардлагагүй. Нэг тоглуулагч ашиглана.
- Сурагч нэрээ сонгож, өмнөх **4 оронтой хавтасны кодоор** өөрийн плейлистээ үүсгэж, нэр/тайлбар засаж, дуу нэмэх/хасах, дараалал солих боломжтой. Плейлистийг хогийн савнаас сэргээж болно. Нэг сурагч 30 плейлист, нэг плейлист 250 дуу хүртэл.
- Ангийн плейлист, Spotify дууны ID болон мэдээлэл **`database/music/`** дотор хадгалагдана. Эдгээр нь Spotify бүртгэлийн плейлистүүдээс тусдаа. **Дараа нь / Up Next** хэсэг тоглуулах дарааллыг харуулна.
- Аудио upload/import, аудио татах, Music-ийн хадгалсан файл тоглуулах боломж унтарсан. Сайт Spotify аудиог татаж файл болгон хадгалахгүй. Өмнөх хадгалсан файлуудыг устгахгүй. Spotify дууг давхцуулж холихгүй; Spotify-ийн эх artwork, нэр, уран бүтээлч болон эх холбоосыг харуулна.
- PKCE холболт **client secret шаарддаггүй**. Refresh token серверийн PHP сессэд хадгалагдана; SDK богино хугацааны access token хэрэглэнэ. Холболт нэг дэлгэцийн хөтөчид хүчинтэй; хөтчийн сесс дууссан үед дахин холбогдож болно. Нэвтэрсний дараа бүртгэлийн нэр, тайлбар, холболт салгах товчтой самбар харагдахгүй.
- «Сонсох» нь дэлгэцийн SDK төхөөрөмж рүү Spotify playback хүсэлтийг браузераас шууд явуулна. Сайт дээрх удаан transfer + play gateway хүсэлтийг дуу бүрт давтахгүй. API хүсэлтүүд хугацааны хязгаартай; эрх дуусах, Spotify түр хязгаарлах болон сүлжээний алдаа тусдаа тайлбартай.
- Music нь Anthropic API дуудахгүй. Egune чат тусдаа үйлчилгээтэй. [Music-ийн өгөгдөл ба үйлчилгээ](music-privacy.php).

### Spotify холбох

1. Client ID тохируулсан. [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) дээр Redirect URI-г яг **`https://12-2.lol/spotify-callback.php`** гэж хадгална.
2. **Web Playback SDK** сонголтыг идэвхжүүлж, **Users and Access** хэсэгт том дэлгэц дээр ашиглах ганц Premium бүртгэлээ нэмнэ.
3. Сайтын **Music → Spotify-тай холбох** товчоор дэлгэц дээрээ нэвтэрч зөвшөөрөл өгнө. Буцаж ирэхэд Music дотор тоглоно; Spotify тусдаа цонх нээх шаардлагагүй.
4. Шинэчлэхдээ `index.php`, `spotify.php`, `spotify-callback.php`, `inc/spotify.php`, `inc/music.php`, `inc/music-view.php`, `assets/js/spotify.js`, `assets/js/music.js`, `assets/css/music.css`, `music-privacy.php` болон бусад application файлыг хамт байршуулна. **Одоо байгаа `database/` хавтсыг хадгална.**
5. Өөр домэйнд шилжвэл `C122_SPOTIFY_REDIRECT_URI` environment болон Dashboard URI-г ижил болгож шинэчилнэ. `C122_SPOTIFY_CLIENT_ID` environment нь Client ID-г сольж болно.

Заавар: [PKCE](https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow), [Redirect URI](https://developer.spotify.com/documentation/web-api/concepts/redirect_uri), [Spotify тоглуулах API](https://developer.spotify.com/documentation/web-api/reference/start-a-users-playback).

## GOOGLE — сайт доторх хөтөч

- **GOOGLE** хэсэгт Google-ээс хайх (SafeSearch үргэлж асаалттай), сайтын хаяг бичиж нээх, сурах болон тоглоомын хурдан холбоос ашиглана.
- Сурагчид сайт дээрээ үлдэнэ: шинэ таб нээх товч байхгүй. Сайтууд тусгаарласан (sandbox) iframe дотор нээгдэх ба pop-up, шинэ цонх, үндсэн хуудсыг шилжүүлэх эрхгүй. Холбоосыг чирж хаяхад шинэ таб нээгдэхгүй.
- Зарим сайт (Facebook, Instagram, TikTok, Gmail, Google Docs, Khan Academy г.м.) өөр сайт дотор нээгдэхийг хориглодог тул «Энэ сайтыг энд нээх боломжгүй» гэсэн мэдэгдэл гарна. GOOGLE хэсгээс гарахад нээлттэй сайт/тоглоом зогсож, буцаж ороход дахин ачаална.
- Анхаар: хөтчийн өөрийн хулганы баруун товчны «Open link in new tab», Ctrl/дунд товчоор дарах зэргийг вэб хуудас хааж чадахгүй. Бүрэн хаах бол ангийн компьютер/дэлгэцийн Chrome-д URLBlocklist ["*"] болон URLAllowlist [сайтын домэйн, www.google.com, *.wikipedia.org, phet.colorado.edu, lichess.org …] бодлого (policy) эсвэл kiosk горим тохируулна.
- YouTube холбоос YouTube хэсэгт тоглоно. «Миний сайтууд» болон «Сүүлд нээсэн» нь зөвхөн тухайн төхөөрөмжийн хөтөчид хадгалагдана.

## Загвар — Aurora

- Ягаан-цэнхэр «aurora» өнгө, шилэн (glass) хавтгай, Nunito + Unbounded фонт. Цагаан болон харанхуй горимтой.
- Өргөн дэлгэц (1180px+) дээр зүүн талд байнгын цэс, жижиг дэлгэц дээр «Цэс» товчоор нээгдэнэ. Цэс бүлэгтэй: Хичээл, Сурах, Бүтээл ба дурсамж, Чөлөөт цаг.
- Нүүр хуудсанд мэндчилгээ, өдөр, одоогийн хичээл, хурдан нээх 8 товч.
- Хөдөлгөөн: хэсэг солигдоход, гүйлгэхэд гарч ирэх, товч дарахад долгион, цэсийн гулсах тэмдэглэгээ, хөдөлгөөнт арын өнгө. Хэдэн секунд хэн ч хөдлөөгүй үед арын хөдөлгөөн түр зогсож дэлгэцийн ачааллыг бууруулна. Төхөөрөмж «хөдөлгөөн багасгах» тохиргоотой бол хөдөлгөөн унтарна.

## Тоглоомууд — Ludo, Chooser

- **Ludo:** тоглогч бүр нэрээ бичиж, 8 өнгөнөөс сонгоно. Тоглоом автоматаар хадгалагдах тул хуудсаа дахин нээсэн ч «Өмнөх тоглоомоо үргэлжлүүлэх» боломжтой. «Шинэ тоглоом» товч шооноос тусдаа дээд мөрөнд байрлах бөгөөд баталгаажуулалт асууна.
- **Chooser:** камерын царайг дугаарлаж, 3 секундын хүлээлтийн дараа нэгийг томруулж харуулна. Space — сонгох, R — дахин. Царайг зөвхөн тухайн төхөөрөмж дээр боловсруулна.
- Тоглоомын хөгжилтэй дууг хөтөч өөрөө үүсгэнэ (файл татахгүй); дууны товчоор унтраана.

## Сурагчийн дугуйлангийн хуваарь

- «Дугуйлан» хэсэгт **сурагч нэрээ сонгоод «Өнөөдөр» эсвэл «Маргааш»** товчоор тухайн өдөр өөрийн сонгосон ямар дугуйлан байгааг харна. Зөвхөн тэр өдрийн дугуйлан, эхлэх/дуусах цаг, үргэлжлэх минут, танхим гарна; хувийн харагдацад багшийн мэдээлэл харуулахгүй.
- **Өөр огноо** сонгох эсвэл **«Долоо хоног»** товчоор өөрийн бүх өдрийн хуваарийг харж болно. Цагтай дугуйлан байхгүй өдрийг тодорхой тэмдэглэнэ. Бүртгэлийн 1, 2, 3-р сонголтыг дэлгэх боломжтой.
- **Эхлэх эсвэл дуусах хүртэлх хугацаа** секунд тутам Улаанбаатарын цагаар шинэчлэгдэнэ. Сонгосон өдрийн дугуйлан дууссан бол «Дууссан» гэж харагдана; дараагийн долоо хоногийн цаг руу шилжихгүй. Давхцсан цагуудыг тэмдэглэнэ.
- **«Нийт хуваарь»** товчоор нэр сонгохгүйгээр өмнөх бүх хуваарийг үзнэ. Дугуйлангийн «Дэлгэрэнгүй»-д 12-2 ангийн хэн, хэддүгээр сонголтоор сонгосныг харна.
- Цагууд `assets/data/clubs.json`, нэр болон эрэмбэлсэн сонголтууд `assets/data/club-students.json` дотор бий. Хүйс/ангиар ялгасан спортын бүлгийг бүртгэлийн бүлэгтэй тааруулсан. Ерөөлт / Ерөөлтхүү нь нэг сурагчийн бүртгэл; Маргад-Эрдэнийн сонголт өгсөн хүснэгтэд байхгүй тул хоосон байна.
- Эх зурагт **Гитар, Шоо, СӨҮЗ**-ийн цаг байхгүй тул «Цаг хараахан оруулаагүй» гэж харагдана. «Хөгжмийн дугуйлан»-д «Үндэсний хөгжим»-ийн цагийг боломжит тааруулалт болгон үзүүлж, баттай цагийн тоолуурт оруулаагүй. Нэрийг баталгаажуулбал JSON дахь `tentative` тэмдэглэгээг авч болно.
- Нэр сонгосон төлөв тухайн хөтөч дээр хадгалагдана. Дугуйлангийн тоолуур нь эх зургийн долоо хоногийн хуваарийг дагана. Өгсөн бүртгэлээс нийтэд харагдах хэсэгт зөвхөн сурагчийн нэр, анги, дугуйлангийн сонголт болон хуваарь тааруулах бүлэг орсон.

## Дугуйлангийн хуваарь ба дэлгэцийн горим

- «Дугуйлан» хэсэгт өгсөн зургийн **2026–2027 оны I улирлын** дугуйлан, секцийн хуваарийг уншиж болно. 28 хэвлэсэн мөрийн дугаар байгаа боловч Даамын 22–23-р мөр нэгдсэн тул **27 тусдаа дугуйлан** болгон оруулсан.
- Анх 12-р ангид хамаарах хуваарийг харуулна. Бүх дугуйлан, өөр анги эсвэл гараг сонгож, нэр/багш/танхимаар хайна. Ангийн мэдээлэлгүй мөрүүдийг эх зурагт тодорхойгүй гэж тэмдэглэнэ.
- Зургийн «7 хоногт» гэсэн тоог эхээр нь хадгалсан. Давтамж, цагийн тайлбар нь зурагтай зөрөх үед нэмэлт тайлбар харагдана; зурагт байхгүй цагийг нэмээгүй.
- Эх зургийг сайт дотроо томруулж үзэх, татах боломжтой. Хуваарийн өгөгдөл `assets/data/clubs.json`, эх зураг `assets/img/clubs-schedule.jpg` дотор бий. Хуваарь солигдвол эдгээрийг шинэчилнэ.
- Дээд хэсгийн нар/сар товчоор **цагаан болон харанхуй горим** сонгоно. Сонголт тухайн хөтөч дээр хадгалагдаж, сайт, удирдлага болон хуваалцсан хавтасны хуудсанд адил хэрэглэгдэнэ. Анх төхөөрөмжийн горимыг дагана.
- Таб солих, товч, картын хөдөлгөөн зөөлөн анимэйшнтэй. Төхөөрөмж дээр хөдөлгөөн багасгах тохиргоо идэвхтэй бол хөдөлгөөнийг багасгана. Ном, зураг, DOODLE-ийн зурсан хуудасны өнгийг горим солихдоо өөрчлөхгүй.

## СУРАХ БИЧИГ

- [ECONTENT](https://econtent.edu.mn/book/12rangi) болон [MEDLE](https://medle.mn/textbook/12)-ийн 12-р ангийн цахим санд одоогоор байгаа **бүх 10 сурах бичиг** багтсан. Нэрээр хайж, төрлөөр шүүнэ. Номыг албан ёсны эх сайтын уншигчаар сайт дотроо үзэж, шаардлагатай бол эх сайтад тусад нь нээнэ.
- Номын ажлын дэвтэрт өөрийн нэр болон **хувийн хавтасны 4 оронтой кодоор** нэвтэрнэ. Цомгийн кодоос тусдаа.
- Хуудас/сэдэв, тэмдэглэл, зураг болон бодолт **вэбсайтад автоматаар хадгалагдана**. Өөр төхөөрөмжөөс ижил нэр, кодоор нэвтэрч ажлаа үргэлжлүүлнэ. Хадгалсан ажил хувийн хавтсанд хамгаалагдсан JSON файл болж байрлана.
- Олон өнгийн бийрээр зурж, тэмдэглэлийг TXT, бодолтын зургийг PNG хэлбэрээр татаж болно. Хадгалсан зураас үлдэнэ; зөвхөн хадгалаагүй шинэ зураасыг буцааж болно.
- Сүлжээ тасарвал хадгалаагүй ажлын түр хуулбар тухайн төхөөрөмжид үлдэнэ. Дахин нэвтрэхэд сэргээх сонголт гарна. Өөр төхөөрөмжийн шинэ ажлыг хуучин хувилбараар шууд дарж бичихгүй.

## DOODLE — ангийн дурсамжийн самбар

- **Цомгийн ижил кодоор** нэвтэрнэ. Анхдагч код **4200**; удирдлагаас цомгийн код сольсон бол DOODLE мөн шинэ кодыг хэрэглэнэ.
- Өнгө, бийр сонгон зурж, бичвэр, цомгийн зураг болон хувийн хавтасны зураг/GIF оруулж болно. Хувийн хавтасны файл сонгоход тухайн хавтасны код шаардлагатай. `assets/img/doodle/` дотор **6 хөдөлгөөнт GIF sticker** бэлэн бий.
- Хадгалсан зураас болон нэмсэн зүйлсийг арилгахгүй. Дуусгасан хуудсыг зөвхөн үзэж, дараагийн дурсамжаа шинэ хуудсанд бүтээнэ. Хуудсууд вэбсайтад хадгалагдаж, бусад төхөөрөмжөөс нээгдэнэ.
- Самбарт оруулсан зураг/GIF нь тусдаа хуулбартай. Цомог эсвэл хувийн хавтаснаас эх файлыг устгасан ч дурсамжийн зураг үлдэнэ.
- Шинэ хуудас олноор үүсгэж болно; самбарын дээд хязгаар **5000 хуудас / 8 ГиБ**. Сайтын нийт багтаамжийн хязгаарыг мөн мөрдөнө.

## Сурагчдын хавтас

- Нүүр хуудасны **«Хавтас»** табад өгсөн жагсаалтын 18 сурагчийн нэр гарна. Нэрээр хайж болно.
- Нэрээ сонгоод тухайн сурагчийн **4 оронтой нууц үгийг** оруулна. Эхний `0` орно: нууц үгийг яг дөрвөн оронтой бичнэ. Нууц үгийг сервер дээр hash хэлбэрээр хадгална, нэрийн жагсаалтад гаргахгүй.
- Хавтас бүр тусдаа нэвтрэлттэй. Нэг сурагчийн нууц үгээр өөр сурагчийн файлыг нээх боломжгүй. Цомгийн болон админ нэвтрэлтээс тусдаа.
- Үндсэн болон дэд хавтасны **тайлбар, дүрсийг** «Хавтасны мэдээлэл»-ээр өөрчилнө. Үндсэн хавтасны тайлбар, дүрс нэрийн жагсаалтад мөн харагдана.
- **«Шинэ хавтас»** дарж хавтас дотор хавтас үүсгэнэ. Дээд талын замаар өмнөх хавтас руу буцна. Хуучин файлууд үндсэн хавтсандаа хэвээр байна. Дэд хавтас устгахдаа доторх бүх дэд хавтас, файл хамт устахыг баталгаажуулна.
- Файлыг олон сонгон нэмэх, нэрээр хайх, нэрийг өөрчлөх, сонгосон файлуудыг өөрийн дэд хавтас руу **зөөх**, нэг нэгээр нь татах/устгах, сонгосон файлуудыг **ZIP** хэлбэрээр татах/хамтад нь устгах боломжтой. Устгахын өмнө баталгаажуулах цонх гарна.
- **«Хуваалцах»** товчоор бүх хавтас, тухайн дэд хавтас (доторх бүх түвшний файлуудтай), эсвэл ганц файлын холбоос үүсгэнэ. Холбоостой хүнд сурагчийн нууц үг шаардахгүй. Бүх хавтасны холбоос дараа нь нэмсэн файлуудыг мөн харуулна.
- Хавтасны холбоосоор зочин файл үзэх, татах, анхдагчаар **шинэ файл нэмэх** боломжтой. Холбоос үүсгэх үед файл нэмэх эрхийг унтрааж болно. Ганц файлын холбоос зөвхөн үзэх, татах эрхтэй. Зочин одоо байгаа файлыг өөрчлөх, устгах, зөөх эрхгүй. Зочны байршуулалт мөн хэмжээ, багтаамжийн хязгаарыг мөрдөнө.
- **«Холбоос устгах»** хуучин холбоосыг шууд хүчингүй болгоно. **«Шинэ холбоос үүсгэх»** дарвал өмнөх холбоос мөн хүчингүй болж шинэ холбоос гарна. Холбоосыг үүсгэсний дараа хуулж хадгална; дараа нь дахин хуулж авах шаардлагатай бол шинээр үүсгэнэ. Холбоос хүчингүй болбол дуусаагүй зочны байршуулалтыг үргэлжлүүлэх боломжгүй.
- **«Засах»** товчоор текст файлыг шууд өөрчилж хадгална. Баримт, хүснэгт, PDF-ийн энгийн засварлагч болон бүрэн Office засварлагчийн тохиргоог доорх заавраас үзнэ. **«Хөрвүүлэх»** товчоор боломжтой форматаас сонгож хөрвүүлсэн шинэ файлыг хавтасдаа хадгална; эх файл хэвээр үлдэнэ.
- Энгийн засварлагч **32 МиБ** хүртэл файл нээж, өөрчлөлтийг хадгална. Сервер нэг хүсэлтэд үүнээс бага хэмжээ зөвшөөрвөл тухайн хязгаар үйлчилнэ. Өөр цонхонд файл шинэчлэгдсэн бол өмнөх хувилбараар дарж бичихгүй, шинэ хувилбарыг дахин нээхийг хүснэ.
- Зураг, PDF, текст, дуу, видеог хөтөч дотор урьдчилан үзнэ. Хөтөч дэмжихгүй форматтай файлыг татаж аваад тохирох программаар нээнэ.
- PDF урьдчилан үзэхэд шаардлагатай PDF.js нь `assets/js/vendor/pdfjs/` дотор багтсан. Файлыг гаднын хөрвүүлэх үйлчилгээнд илгээхгүй; олон хуудастай PDF-ийн хуудсуудыг өмнөх/дараах товчоор үзнэ.
- Нэг файл **512 МиБ** хүртэл. Файлыг **4 МиБ хүртэлх хэсгээр** байршуулна. Серверийн PHP хязгаар бага бол хэсэг нь багасна. Явцыг харж, байршуулалтыг зогсоож болно.
- Нэг удаагийн хамтын үйлдэлд **200 файл** хүртэл сонгоно. ZIP таталтын нийт хэмжээ **4 ГиБ-аас бага** байна. Хавтас бүрийн багтаамж **10 ГиБ**, бүх хавтасны нийт хязгаар **100 ГиБ**; сайтын нийт багтаамжийн хязгаарыг мөн мөрдөнө.
- **«Түгжих»** дарж хавтсаасаа гарна. Нэвтрэлт 12 цаг хүчинтэй, хөтөч хаахад дуусна. Олон удаа буруу нууц үг оруулахад түр түгжинэ.
- Шинэчлэл суулгахдаа `index.php`, `share.php`, `api.php`, `inc/`, `assets/`-ийн шинэ файлуудыг хуулна. **`database/` доторх хуучин өгөгдлөө дарж бичихгүй, устгахгүй.** Хавтасны өгөгдөл анх «Хавтас» табыг нээхэд автоматаар үүснэ.

## Цомогт том файл байршуулах (Cloudflare)

- Файлыг хөтөч дээр **хэсэг хэсгээр** (≤ 48 МБ) илгээдэг. Тиймээс Cloudflare-ийн 100 МБ-ийн хязгаар саад болохгүй, нэг файлын хэмжээнд хязгаар байхгүй.
- Нийт багтаамжийн хязгаар анхдагчаар **500 ГБ**. Удирдлага → Зургийн сан хэсгээс өөрчилнө.
- Интернэт тасарвал ижил файлыг дахин сонгоход тасарсан газраасаа үргэлжилнэ.
- **Хурд:** жижиг зураг бүрийг нэг хүсэлтээр, том видеог 4 хэсгээр нь зэрэг илгээнэ (нийт 5 хүсэлт зэрэг). Мянга мянган файл сонгосон ч самбар хураангуйлагдаж, хуудас гацахгүй. Жижиг зургийг хөтөч өөрөө үүсгэдэг тул байршуулж буй хүн хуудсаа нээлттэй байлгавал цомог хурдан ачаална.
- Зургийн жагсаалтыг `database/media-index.php`, `database/media-journal.php` файлд хадгалдаг тул олон мянган файлтай үед ч цомог хурдан нээгдэнэ. SFTP-ээр шууд нэмсэн файл 15 минутын дотор цомогт гарна.
- `.user.ini` нь PHP-ийн `post_max_size`-ийг 64 МБ болгодог. Хэрэв хостинг үүнийг уншихгүй бол сайт сервер зөвшөөрсөн хэмжээнд тааруулж хэсгийг автоматаар багасгана. Энэ үед ажиллана, гэхдээ арай удаан байна.
- nginx-ийн `client_max_body_size` бага байсан ч хэсгийн хэмжээ автоматаар багасна.

## Хуваарь солих

Удирдлага → **Хуваарь устгах**, дараа нь **Хуваарь оруулах** гэж дарна.

- **PDF**: сургуулийн хуваарийн PDF-г оруулбал сайт дээрх ангийн (жишээ нь 12-2) хичээлүүдийг автоматаар ялгана. Мөн 12-р ангийн нийтлэг хичээлүүдийг (12A/12B англи хэл, HSK хятад хэл, «12 сонгон») ялгана. Даасан багш, танхим, хонхны цагийг ч автоматаар авна.
- **CSV (Excel)**: «Гараг, Цаг, Хичээл, Багш, Бүлэг, Танхим, Тэмдэглэл» баганатай байна. Загвар авахын тулд эхлээд «CSV (Excel)» товчоор татаж аваарай.
- **JSON**: «JSON» товчоор татаж авсан файл.

Хадгалах, устгах бүрт өмнөх хувилбар нөөцлөгдөнө. **Нөөц** товчоор сэргээнэ.
